## 🌿 Branch Naming Guide

### Format

```text
type/short-task-name
```

### Examples

```text
feature/auth-module
feature/products-crud
feature/cart-module
feature/orders-module

fix/login-validation
fix/cart-total

refactor/products-service

docs/update-readme

chore/project-setup
chore/setup-typeorm
chore/configure-eslint

test/auth-service
```

### Branch Types

| Prefix      | Description                                             |
| ----------- | ------------------------------------------------------- |
| ✨ feature  | New feature or functionality                            |
| 🐛 fix      | Bug fix                                                 |
| ♻️ refactor | Improve code without changing behavior                  |
| 📝 docs     | Documentation updates                                   |
| 🔧 chore    | Project setup, configuration, dependencies, maintenance |
| ✅ test     | Unit or Integration tests                               |

## 💬 Commit Message Guide

### Format

```text
type(scope): message
```

### Examples

```text
feat(auth): create auth module

feat(products): implement products CRUD

feat(cart): add cart endpoints

fix(cart): fix total price calculation

refactor(auth): simplify jwt strategy

docs(readme): update project documentation

chore(project): setup TypeORM configuration

test(auth): add login unit tests
```
